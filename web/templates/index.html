LodeSTAR Overview

LodeSTAR means Localization and detection from Symmetries, Translations And Rotations. It is a self-supervised microscopy detector: instead of needing manually labelled particle centers, it learns from transformed versions of the same particle image.

The model predicts a dense map over the image. At each pixel it estimates an x displacement, a y displacement, and a confidence value. Detection then converts those dense predictions into particle centers.

Training

  • Samples are crops of one particle class. They define what the model should detect.
  • Transforms are random rotations, shifts, intensity changes, and other augmentations used to create the self-supervised training signal.
  • Epochs are full passes over the generated training samples. More epochs can improve the model but take longer.

Detection

  • Standard mode uses the LodeSTAR confidence map and local maxima to find particle centers.
  • Area mode keeps connected high-confidence regions whose size is inside the configured area range.
  • Watershed mode separates touching high-confidence regions using seed spacing and minimum area parameters.
  • Template mode first detects positions, then compares a rotated crop template around each detection to estimate orientation angle phi.

Orientation

Template-mode orientation needs a crop with a known reference angle. In the Training sample view, enable Store template direction, draw the direction arrow on the crop, and add it to the pool. Detection can then use that crop as the template.

The batch detection CSV stores phi as the orientation angle in radians and orientation_ncc as the template-match quality score.

Tracking

  • Non-maximum suppression removes duplicate detections that are too close in the same frame.
  • Hungarian linking assigns detections between consecutive frames using the globally shortest valid set of links.
  • Gap interpolation fills short missing segments and marks those rows as interpolated.

Analysis

  • Mean squared displacement measures how far particles move as a function of time lag.
  • Active Brownian Particle fitting estimates physical parameters such as translational diffusion, propulsion speed, and rotational diffusion.
  • Angular mean squared displacement needs finite orientation values. If tracks were made without template mode, angular results are omitted.

Janus Crescent Ratio

The crescent-ratio tool measures the segmented bright or dark crescent area divided by the rim-excluded Janus particle disk area. It is saved as a CSV plus a quality-control overlay.

Theta is the polar cosine angle: ratios 1, 0.5, and 0 correspond to 0, 90, and 180 degrees. Out-of-plane angle retains the one-sided sine convention: ratios 0.5, 0.25, and 0 correspond to 0, 30, and 90 degrees.

Both mappings assume an ideal half-coated sphere. Experimental calibration is still recommended when focus or contrast changes.

File Terms

  • TDMS is National Instruments Technical Data Management Streaming format, commonly used for instrument data.
  • CSV is a comma-separated values table used here for detections, tracks, and analysis outputs.
  • FPS means frames per second for video export and playback.
